# Specification

## Summary
**Goal:** Add subject deletion with chapter archiving, enhance AI suggester with timeline and test score prioritization, add test analytics with progress bars and graphs, implement study session summaries with AI formatting, add emojis to topics, apply Spider-Man + CA theme throughout, add countdown timer to final exam, reorganize Study tab, and add Spider-Man logo to main page.

**Planned changes:**
- Add subject deletion option that moves chapters to an archive/unassigned section where they remain viewable but unlinked
- Enhance AI suggester to prioritize subjects based on timeline proximity and test scores in addition to existing completion and revision logic
- Add progress bars for each subject in test tracking interface showing test performance
- Add analytical graphs visualizing test performance trends and statistics
- Add study session summary section where users write summaries and important topics, then AI formats the text for final revision reference
- Add cute emojis to each topic throughout the application
- Apply Spider-Man + CA themed design with red and blue color scheme and web patterns while maintaining professional academic focus
- Add countdown timer in top right showing days remaining until May 1, 2028
- Reorganize Study tab to show all subjects with revision tracking in same view with individual progress for each subject
- Add Spider-Man logo to main page

**User-visible outcome:** Users can delete subjects while preserving chapters in an archive, receive AI suggestions based on timelines and test scores, view test analytics with progress bars and graphs, write and AI-format study session summaries, see cute emojis on topics, experience a Spider-Man + CA themed interface with web patterns and red/blue colors, track days to final exam with a countdown timer, view all subjects and revisions in a unified Study tab, and see the Spider-Man logo prominently on the main page.
